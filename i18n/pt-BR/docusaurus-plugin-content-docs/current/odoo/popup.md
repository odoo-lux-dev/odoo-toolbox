# Popup da extensão

O popup da extensão reúne as ações mais comuns em um único clique no ícone da extensão na barra de ferramentas do seu navegador.

## Abrindo o popup {/* #opening-the-popup */}

Clique no ícone do **Odoo Toolbox** na barra de ferramentas do seu navegador. O popup abre imediatamente.

:::tip
Se o ícone não estiver visível, ele pode estar oculto no menu de extensões do seu navegador. Fixe-o para acesso rápido.
:::

![Odoo Toolbox - Popup](/img/popup/popup.png)

## Modo debug {/* #debug-mode */}

O popup exibe o status atual do modo debug e permite alterná-lo facilmente. O modo debug é ativado automaticamente nas páginas Odoo quando está ativado na extensão.

- **1 clique**: ativa/desativa o modo debug
- **2 cliques**: ativa o modo debug de assets (equivalente a `?debug=assets`)
- **3 cliques**: ativa o modo de assets e testes (equivalente a `?debug=assets,tests`)

## Tema da extensão {/* #extension-theme */}

Escolha a aparência da interface do Odoo Toolbox (painel DevTools, barra lateral técnica, popup, opções):

- **Light**: tema claro
- **Dark**: tema escuro

## Barra lateral técnica {/* #technical-sidebar */}

Ative ou desative a [barra lateral técnica](./technical-sidebar) diretamente do popup, sem precisar abrir as configurações.

## Favoritos Odoo.SH {/* #odoosh-favorites */}

O popup exibe a lista dos seus projetos favoritos do Odoo.SH para acesso rápido. Clique em um favorito para abrir o projeto correspondente no [Odoo.SH](https://www.odoo.sh) diretamente.

Essa funcionalidade está disponível em todas as páginas, mesmo fora do Odoo.SH.

:::info
A adição e remoção de favoritos é feita diretamente pela interface do Odoo.SH. A renomeação e a reordenação são feitas através das opções da extensão.

Para mais informações, consulte as seções [Projetos favoritos](../odoosh/favorites) e [Options](../options).
:::
