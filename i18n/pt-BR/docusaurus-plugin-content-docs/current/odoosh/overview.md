# Odoo.SH

O Odoo Toolbox adiciona um conjunto de funcionalidades diretamente na interface do Odoo.SH para simplificar o gerenciamento de projetos e branches. Essas funcionalidades estão disponíveis apenas no [Odoo.SH](https://www.odoo.sh).

## O que está incluído {/* #whats-included */}

### [Projetos favoritos](./favorites) {/* #project-favorites */}

A funcionalidade principal do Odoo.SH. Marque seus projetos mais usados, dê a eles nomes de exibição personalizados e mantenha-os ordenados como desejar - para que você sempre encontre o que precisa em um relance.

### [Recursos adicionais](./additional-features) {/* #additional-features */}

Utilitários que melhoram seu fluxo de trabalho diário no Odoo.SH: cópia do nome de branch, links do GitHub, integração de tarefas, indicadores de status de build adaptados para daltônicos e muito mais.
