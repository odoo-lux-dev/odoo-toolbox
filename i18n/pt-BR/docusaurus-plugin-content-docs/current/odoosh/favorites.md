# Projetos favoritos

Os projetos favoritos são a funcionalidade principal da parte Odoo.SH do Odoo Toolbox. Eles permitem fixar seus projetos Odoo.SH mais usados, dar a eles nomes personalizados e reordená-los como desejar - para que você possa acessar o que precisa em um relance, sem precisar procurar em toda a lista de projetos.

Os favoritos são acessíveis a partir de três lugares:

- O **popup da extensão** - em qualquer página, mesmo fora do Odoo.SH.
- A **página inicial do Odoo.SH** - os favoritos são exibidos no topo da lista de projetos.
- A **página de opções da extensão** - uma seção dedicada ao gerenciamento dos seus favoritos.

## Adicionar um favorito {/* #adding-a-favorite */}

A partir da lista de projetos no [Odoo.SH](https://www.odoo.sh), o Odoo Toolbox adiciona um ícone ⭐ ao lado de cada projeto. Clique nele para fixar o projeto nos seus favoritos.

![Projetos favoritos - adicionar um favorito](/img/odoosh/favorites/projects-list.png)

:::tip
Você pode adicionar quantos projetos quiser aos seus favoritos. A ordem em que eles aparecem é totalmente personalizável.
:::

## Renomear um favorito {/* #renaming-a-favorite */}

Por padrão, um favorito exibe o nome do projeto como ele aparece no Odoo.SH. Você pode atribuir um nome de exibição personalizado, o que é útil quando os nomes dos projetos são longos, pouco claros ou quando você gerencia vários projetos semelhantes.

Para renomear um favorito, acesse as opções da extensão Odoo Toolbox e depois a seção "SH Favorites". Clique no botão de edição do favorito que deseja renomear, digite o novo nome e pressione Enter para salvar.

![Projetos favoritos - renomear](/img/odoosh/favorites/rename-favorite.png)

## Reordenar favoritos {/* #reordering-favorites */}

Os favoritos podem ser reordenados via arrastar e soltar a partir das opções da extensão. Use a alça de arrasto à esquerda de cada favorito para movê-lo para cima ou para baixo na lista. A ordem que você definir é aquela exibida na página inicial do Odoo.SH e no popup da extensão.

## Remover um favorito {/* #removing-a-favorite */}

Clique novamente no ícone ⭐ de um projeto fixado para removê-lo dos seus favoritos. O projeto permanece normalmente acessível na lista completa de projetos do Odoo.SH. Você também pode remover um favorito a partir das opções da extensão clicando no botão de exclusão à direita do favorito que deseja remover.

## Acessar favoritos pelo popup {/* #popup-access */}

O popup da extensão exibe seus favoritos em todas as páginas, incluindo fora do Odoo.SH. Clique em um favorito no popup para abrir o projeto correspondente no [Odoo.SH](https://www.odoo.sh) diretamente.

![Projetos favoritos - acesso pelo popup](/img/odoosh/favorites/popup-list.png)

:::info
Para abrir um projeto em uma nova aba, mantenha pressionada a tecla <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> no Mac) enquanto clica no favorito no popup. Você também pode clicar com o botão do meio para abrir o projeto em uma nova aba.
:::
