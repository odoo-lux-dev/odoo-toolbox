# शुरुआत

**Odoo Toolbox** का उद्देश्य विभिन्न टूल्स और फीचर्स जोड़कर Odoo और Odoo.SH यूज़र्स और डेवलपर्स के अनुभव को बेहतर बनाना है।

## इंस्टॉलेशन {/* #installation */}

### Chromium {/* #chromium */}

1. [Chrome Web Store](https://chromewebstore.google.com/detail/odoo-toolbox/jgobnmpfeomiffhbedhfgbhelcnnelkd) पर जाएं
2. **Add to Chrome** पर क्लिक करें
3. **Add extension** पर क्लिक करके पुष्टि करें

### Firefox {/* #firefox */}

1. [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/odoo-toolbox/) पेज पर जाएं
2. **Add to Firefox** पर क्लिक करें
3. **Add** पर क्लिक करके पुष्टि करें

एक बार इंस्टॉल होने के बाद, आपके ब्राउज़र टूलबार में Odoo Toolbox आइकन दिखाई देगा।

---

## त्वरित शुरुआत {/* #quick-start */}

### 1. किसी Odoo इंस्टेंस पर जाएं {/* #navigate-to-odoo */}

अपना ब्राउज़र खोलें और **वर्शन 14 या उच्चतर** चलाने वाले किसी भी Odoo इंस्टेंस पर जाएं।

### 2. पॉपअप खोलें {/* #open-the-popup */}

अपने ब्राउज़र टूलबार में **Odoo Toolbox** आइकन पर क्लिक करें। यहां से आप ये कर सकते हैं:

- **Debug mode** को ऑन या ऑफ करें (कीबोर्ड शॉर्टकट से भी उपलब्ध)
- एक्सटेंशन का **थीम** लाइट और डार्क के बीच बदलें
- अपने **Odoo.SH प्रोजेक्ट फेवरेट्स** तक पहुंचें
- एडवांस्ड सेटिंग्स के लिए **Options पेज** खोलें

### 3. Technical Sidebar के साथ फ़ील्ड्स इंस्पेक्ट करें {/* #inspect-fields */}

किसी भी Odoo व्यू पर, पेज के निचले-दाएं कोने (डिफ़ॉल्ट रूप से) में एक **फ्लोटिंग बटन** दिखाई देता है।

1. **Technical Sidebar** खोलने के लिए बटन पर क्लिक करें
2. वर्तमान पेज के बारे में तकनीकी जानकारी देखें (मॉडल, फ़ील्ड्स, व्यू, आदि)
3. अधिक सटीकता के लिए, ऊपर दाएं कर्सर आइकन पर क्लिक करके **एलिमेंट सिलेक्टर मोड** सक्षम करें
4. पेज पर किसी भी फ़ील्ड पर क्लिक करके उसकी तकनीकी जानकारी देखें:
    - फ़ील्ड नाम (`name`, `partner_id`, ...)
    - फ़ील्ड प्रकार (`Many2one`, `Char`, `Selection`, ...)
    - अतिरिक्त गुण और मेटाडेटा

### 4. DevTools पैनल का उपयोग करें {/* #use-devtools-panel */}

DevTools पैनल आपको अपना ब्राउज़र छोड़े बिना Odoo RPC लेयर के साथ इंटरैक्ट करने की अनुमति देता है।

1. अपने ब्राउज़र के **DevTools** खोलें (`F12` या `Ctrl+Shift+I` / Mac पर `Cmd+Option+I`)
2. **Odoo Toolbox** टैब पर जाएं
3. एक ऑपरेशन टैब चुनें:
    - **Search** - डोमेन फिल्टर और फ़ील्ड चयन के साथ रिकॉर्ड्स क्वेरी करें
    - **Write / Create / Unlink** - JSON इनपुट के साथ रिकॉर्ड्स एडिट करें
    - **Call Method** - कोई भी मॉडल मेथड निष्पादित करें
