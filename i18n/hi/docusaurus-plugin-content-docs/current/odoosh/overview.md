# Odoo.SH

Odoo Toolbox प्रोजेक्ट और ब्रांच प्रबंधन को सरल बनाने के लिए Odoo.SH इंटरफ़ेस में सीधे फीचर्स का एक सेट जोड़ता है। ये फीचर्स केवल [Odoo.SH](https://www.odoo.sh) पर उपलब्ध हैं।

## क्या शामिल है {/* #whats-included */}

### [प्रोजेक्ट फेवरेट्स](./favorites) {/* #project-favorites */}

Odoo.SH के लिए फ़्लैगशिप फीचर। अपने सबसे ज़्यादा उपयोग किए जाने वाले प्रोजेक्ट्स को स्टार करें, उन्हें कस्टम डिस्प्ले नाम दें, और अपनी पसंद के अनुसार क्रमबद्ध रखें - ताकि आपको जो चाहिए वह हमेशा एक नज़र में मिल जाए।

### [अतिरिक्त फीचर्स](./additional-features) {/* #additional-features */}

यूटिलिटीज़ जो आपके दैनिक Odoo.SH वर्कफ़्लो को बेहतर बनाती हैं: ब्रांच नाम कॉपी, GitHub लिंक, टास्क इंटीग्रेशन, कलरब्लाइंड-फ्रेंडली बिल्ड स्टेटस इंडिकेटर्स, और बहुत कुछ।
