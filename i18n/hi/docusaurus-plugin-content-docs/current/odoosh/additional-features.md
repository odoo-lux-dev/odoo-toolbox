# अतिरिक्त फीचर्स

यह पेज उन छोटे यूटिलिटीज़ को कवर करता है जो Odoo Toolbox Odoo.SH इंटरफ़ेस में जोड़ता है ताकि आपके दैनिक प्रोजेक्ट और ब्रांच प्रबंधन में आसानी हो। ये फीचर्स सीधे [Odoo.SH](https://www.odoo.sh) पर उपलब्ध हैं, बिना किसी कॉन्फ़िगरेशन की आवश्यकता के।

## ब्रांच शॉर्टकट्स {/* #branch-shortcuts */}

![ब्रांच शॉर्टकट्स](/img/odoosh/additional-features/shortcuts.png)

### ब्रांच नाम कॉपी {/* #branch-name-copy */}

किसी Odoo.SH प्रोजेक्ट पेज पर प्रत्येक ब्रांच की पंक्ति में ब्रांच नाम के आगे एक **कॉपी आइकन** होता है। ब्रांच नाम को तुरंत अपने क्लिपबोर्ड पर कॉपी करने के लिए उस पर क्लिक करें - `git checkout` कमांड्स, कमिट मैसेज, या टास्क नामों के लिए आसान।

{/* ![ब्रांच नाम कॉपी](/img/odoosh/additional-features/branch-copy.png) */}

### GitHub लिंक {/* #github-links */}

Odoo Toolbox हर ब्रांच पर एक सीधा **GitHub लिंक** जोड़ता है, जो आपके GitHub रिपॉज़िटरी में संबंधित ब्रांच की ओर इशारा करता है। अब GitHub पर अलग से जाने और सही ब्रांच खोजने की ज़रूरत नहीं।

{/* ![GitHub लिंक](/img/odoosh/additional-features/github-links.png) */}

### टास्क इंटीग्रेशन {/* #task-integration */}

Odoo Toolbox किसी Odoo.SH ब्रांच को आपके Odoo प्रोजेक्ट में किसी टास्क के साथ जोड़ सकता है। जब ब्रांच नाम में कोई मैच डिटेक्ट किया जाता है, तो ब्रांच के आगे टास्क का सीधा लिंक दिखाया जाता है।

#### यह कैसे काम करता है

एक्सटेंशन रेगुलर एक्सप्रेशन `/-(\d+)-/` का उपयोग करके प्रत्येक ब्रांच नाम का विश्लेषण करता है। कैप्चर की गई न्यूमेरिक ID को फिर `{{task_id}}` प्लेसहोल्डर के माध्यम से एक कस्टमाइज़ेबल URL में इंजेक्ट किया जाता है। regex और URL दोनों को एक्सटेंशन options से कस्टमाइज़ किया जा सकता है।

डिफ़ॉल्ट पैटर्न इस फॉर्मेट से मेल खाता है: `VERSION-TASKID-OPTIONAL_DESCRIPTION`

पहचाने गए ब्रांच नामों के उदाहरण: `17.0-12345-my-feature`, `15.0-6789-fixes`

टारगेट URL कॉन्फ़िगर करने के लिए, **एक्सटेंशन options** में जाएं और `{{task_id}}` प्लेसहोल्डर के साथ URL सेट करें। उदाहरण के लिए:

```
https://my-odoo.com/odoo/project/task/{{task_id}}
```

:::tip
आप एक्सटेंशन options में **SH Favorites** पेज से प्रति फेवरेट एक विशिष्ट URL सेट कर सकते हैं।
:::
