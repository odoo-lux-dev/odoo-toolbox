# एक्सटेंशन पॉपअप

एक्सटेंशन पॉपअप आपके ब्राउज़र टूलबार में एक्सटेंशन आइकन पर एक क्लिक के साथ सबसे सामान्य एक्शन्स को एक जगह लाता है।

## पॉपअप खोलना {/* #opening-the-popup */}

अपने ब्राउज़र टूलबार में **Odoo Toolbox** आइकन पर क्लिक करें। पॉपअप तुरंत खुल जाएगा।

:::tip
यदि आइकन दिखाई नहीं दे रहा है, तो यह आपके ब्राउज़र के एक्सटेंशन मेनू में छिपा हो सकता है। त्वरित पहुंच के लिए इसे पिन करें।
:::

![Odoo Toolbox - पॉपअप](/img/popup/popup.png)

## Debug mode {/* #debug-mode */}

पॉपअप वर्तमान debug mode की स्थिति दिखाता है और आपको इसे आसानी से टॉगल करने की अनुमति देता है। एक्सटेंशन में सक्रिय होने पर Debug mode Odoo पेजों पर स्वचालित रूप से सक्षम हो जाता है।

- **1 क्लिक**: debug mode ऑन/ऑफ करता है
- **2 क्लिक्स**: assets debug mode सक्षम करता है (`?debug=assets` के बराबर)
- **3 क्लिक्स**: assets और tests mode सक्षम करता है (`?debug=assets,tests` के बराबर)

## एक्सटेंशन थीम {/* #extension-theme */}

Odoo Toolbox इंटरफ़ेस (DevTools पैनल, Technical Sidebar, पॉपअप, options) की दिखावट चुनें:

- **Light**: लाइट थीम
- **Dark**: डार्क थीम

## Technical Sidebar {/* #technical-sidebar */}

सेटिंग्स खोले बिना, सीधे पॉपअप से [Technical Sidebar](./technical-sidebar) सक्षम या अक्षम करें।

## Odoo.SH फेवरेट्स {/* #odoosh-favorites */}

पॉपअप त्वरित पहुंच के लिए आपके पसंदीदा Odoo.SH प्रोजेक्ट्स की सूची दिखाता है। एक फेवरेट पर क्लिक करें और संबंधित प्रोजेक्ट सीधे [Odoo.SH](https://www.odoo.sh) पर खुलेगा।

यह फीचर सभी पेजों पर उपलब्ध है, तब भी जब आप Odoo.SH के बाहर हों।

:::info
फेवरेट्स जोड़ना और हटाना सीधे Odoo.SH इंटरफ़ेस से किया जाता है। रीनेमिंग और रीऑर्डरिंग एक्सटेंशन options के माध्यम से की जाती है।

अधिक जानकारी के लिए, [पसंदीदा प्रोजेक्ट्स](../odoosh/favorites) और [Options](../options) सेक्शन देखें।
:::
