# Odoo

Odoo Toolbox डेवलपर्स और पावर यूज़र्स के लिए डिज़ाइन किए गए टूल्स के सेट के साथ किसी भी Odoo इंस्टेंस पर आपके अनुभव को बेहतर बनाता है। ये फीचर्स सभी समर्थित Odoo databases (v14+) पर उपलब्ध हैं।

## क्या शामिल है {/* #whats-included */}

### [एक्सटेंशन पॉपअप](./popup) {/* #extension-popup */}

सबसे सामान्य डेवलपर एक्शन्स तक त्वरित पहुंच: debug mode टॉगल करें, एक्सटेंशन थीम बदलें, और अपने Odoo.SH फेवरेट्स पर जाएं।

### [Technical Sidebar](./technical-sidebar) {/* #technical-sidebar */}

एक फ्लोटिंग इंस्पेक्शन पैनल जो किसी भी Odoo पेज पर ओवरले करता है। किसी भी फ़ील्ड पर क्लिक करें और उसका तकनीकी नाम, प्रकार और मेटाडेटा रियल-टाइम में देखें।

### [DevTools पैनल](./devtools-panel) {/* #devtools-panel */}

आपके ब्राउज़र DevTools में एम्बेडेड पूर्ण RPC टेस्टिंग इंटरफ़ेस। मॉडल्स क्वेरी करें, रिकॉर्ड्स बनाएं या अपडेट करें, और कस्टम मेथड्स कॉल करें, बिना अपना ब्राउज़र छोड़े।

### [अतिरिक्त फीचर्स](./additional-features) {/* #additional-features */}

छोटे फीचर्स जो आपके Odoo अनुभव को बेहतर बनाते हैं: रिकॉर्ड्स पर तकनीकी मॉडल नाम डिस्प्ले, PDF/HTML रिपोर्ट जनरेशन, और बहुत कुछ।
