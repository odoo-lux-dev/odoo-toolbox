# अतिरिक्त फीचर्स

यह पेज Odoo Toolbox के उन हल्के फीचर्स को कवर करता है जो अपने आप में पूर्ण टूल हुए बिना Odoo इंस्टेंसेस पर आपके दैनिक अनुभव को बेहतर बनाते हैं।

## तकनीकी मॉडल नाम {/* #model-name */}

किसी भी Odoo रिकॉर्ड पेज पर, Odoo Toolbox वर्तमान मॉडल का तकनीकी नाम सीधे इंटरफ़ेस में दिखाता है। यह जानकारी ऐतिहासिक रूप से पेज URL में मौजूद थी, लेकिन वर्शन 17.2 के बाद से ऐसा नहीं है।

इसलिए यह मॉडल नाम केवल Odoo वर्शन 17.2 और बाद के वर्शन पर दिखाया जाता है।

![तकनीकी मॉडल नाम](/img/additional-features/technical-name.png)

:::tip
यह तब विशेष रूप से उपयोगी है जब आप Python कोड, एक्सेस रूल्स, या XML व्यूज़ लिख रहे हों और आपको सटीक मॉडल नाम की आवश्यकता हो।
:::

## PDF / HTML रिपोर्ट प्रीव्यू {/* #report-preview */}

Odoo Toolbox किसी रिकॉर्ड के प्रिंट विकल्पों से सीधे रिपोर्ट्स तक त्वरित पहुंच जोड़ता है। आप हर बार रिपोर्ट डाउनलोड किए बिना संबंधित रिपोर्ट **PDF** या **HTML** फॉर्मेट में एक्सेस कर सकते हैं।

![रिपोर्ट प्रीव्यू](/img/additional-features/report-preview.png)

## त्वरित लॉगिन बटन

Odoo Toolbox Odoo लॉगिन पेजों पर त्वरित लॉगिन बटन जोड़ता है। तीन बटन उपलब्ध हैं:

- Admin
- Demo
- Portal

:::tip
यह डेवलपमेंट या टेस्ट इंस्टेंसेस पर, और Odoo runbots पर भी विशेष रूप से उपयोगी है।
:::

![त्वरित लॉगिन बटन](/img/additional-features/quick-connect-buttons.png)
