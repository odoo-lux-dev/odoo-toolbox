# Technical Sidebar

:::warning
यह फीचर केवल Odoo वर्शन 16 और बाद के वर्शन का समर्थन करता है।
:::

Technical Sidebar एक फ्लोटिंग इंस्पेक्शन पैनल है जो किसी भी Odoo पेज पर ओवरले करता है। यह आपको पेज छोड़े या DevTools खोले बिना रियल-टाइम में फ़ील्ड्स, उनके प्रकार, गुण और मेटाडेटा इंस्पेक्ट करने की अनुमति देता है।

## साइडबार सक्रिय करना {/* #activate-the-sidebar */}

साइडबार [एक्सटेंशन पॉपअप](./popup) से सक्रिय होता है: अपने ब्राउज़र टूलबार में एक्सटेंशन आइकन पर क्लिक करें, फिर **Technical Sidebar** टॉगल सक्षम करें। इसे [एक्सटेंशन options](../options) से भी सक्रिय किया जा सकता है।

## ओवरव्यू {/* #overview */}

साइडबार पेज के किनारे एक एंकर पैनल के रूप में है। इसमें शामिल हैं:

- **Database जानकारी**: वर्तमान database के बारे में जानकारी दिखाता है, जैसे इसका नाम, वर्शन, आदि।
- **रिकॉर्ड जानकारी**: वर्तमान व्यू के रिकॉर्ड के बारे में जानकारी दिखाता है, जैसे इसकी ID, मॉडल, आदि।
- **फ़ील्ड लिस्ट**: वर्तमान मॉडल के सभी फ़ील्ड्स कुछ तकनीकी जानकारी के साथ दिखाता है।
- **एक्शन लिस्ट**: वर्तमान मॉडल के लिए सभी उपलब्ध एक्शन्स कुछ तकनीकी जानकारी के साथ दिखाता है।
- **सर्च बार**: तकनीकी नाम, डिस्प्ले लेबल, या प्रकार के अनुसार फ़ील्ड और एक्शन लिस्ट को फ़िल्टर करता है।

![Technical Sidebar - इंटरफ़ेस](/img/technical-sidebar/interface.png)

:::info
जानकारी तक पहुंचने के लिए Debug mode सक्षम होना आवश्यक नहीं है।
:::

## फीचर्स {/* #features */}

### Database जानकारी {/* #database-information */}

वर्तमान database के बारे में जानकारी साइडबार के शीर्ष पर दिखाई देती है, जिसमें शामिल हैं:

- Odoo वर्शन
- Database का नाम
- वर्तमान भाषा
- डेवलपर मोड की स्थिति

![Technical Sidebar - database जानकारी](/img/technical-sidebar/database-information.png)

### रिकॉर्ड जानकारी {/* #record-information */}

वर्तमान व्यू के रिकॉर्ड के बारे में जानकारी database जानकारी के नीचे दिखाई देती है, जिसमें शामिल हैं:

- मॉडल का नाम (जैसे `res.partner`, `sale.order`)
- रिकॉर्ड ID
- व्यू प्रकार (जैसे `form`, `list`, `kanban`)
- एक्शन प्रकार (जैसे `ir.actions.act_window`)
- एक्शन का नाम (जैसे `Show Partners`)
- एक्शन ID
- एक्शन XML ID (जैसे `base.action_res_partner_form`)
- एक्शन context (जैसे `{'search_default_group_by_country': 1}`)

![Technical Sidebar - रिकॉर्ड जानकारी](/img/technical-sidebar/record-information.png)

#### एक्शन बटन {/* #action-buttons */}

इस सेक्शन में कई एक्शन बटन भी उपलब्ध हैं जो विभिन्न एक्शन्स करने की अनुमति देते हैं:

- मॉडल फ़ील्ड्स दिखाएं
- मॉडल एक्सेस राइट्स दिखाएं
- मॉडल रिकॉर्ड रूल्स दिखाएं
- मॉडल के लिए उपलब्ध एक्शन्स दिखाएं
- वर्तमान व्यू से जुड़ा एक्शन दिखाएं
- वर्तमान रिकॉर्ड डेटा JSON के रूप में दिखाएं

![Technical Sidebar - एक्शन बटन](/img/technical-sidebar/record-actions.png)

### फ़ील्ड और एक्शन लिस्ट {/* #fields-and-actions-list */}

वर्तमान मॉडल के फ़ील्ड्स और एक्शन्स कुछ तकनीकी जानकारी के साथ साइडबार में लिस्ट किए जाते हैं। किसी विशिष्ट फ़ील्ड या एक्शन को त्वरित खोजने के लिए फ़िल्टर और एक सर्च बार भी उपलब्ध हैं।

लिस्ट में किसी आइटम पर होवर करने से उसे पेज पर हाइलाइट किया जाता है, जिससे आप इसे विज़ुअली पहचान सकते हैं।

![Technical Sidebar - होवर](/img/technical-sidebar/fields-highlight.png)

### फ़ील्ड या एक्शन विवरण {/* #field-or-action-details */}

एक मोड को सक्षम करना भी संभव है जो आपको किसी फ़ील्ड या एक्शन पर क्लिक करके उसके तकनीकी विवरण साइडबार में दिखाने की अनुमति देता है। यह आपको उस विशिष्ट फ़ील्ड या एक्शन के बारे में केंद्रित जानकारी देता है।

इस मोड को साइडबार के ऊपरी-दाएं में इंस्पेक्शन बटन पर क्लिक करके सक्षम किया जाता है।

![Technical Sidebar - इंस्पेक्शन मोड](/img/technical-sidebar/field-selected.png)
