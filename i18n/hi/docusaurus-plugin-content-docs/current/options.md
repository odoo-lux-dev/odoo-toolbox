# Options

Options पेज Odoo Toolbox की सभी सेटिंग्स को एक ही जगह पर एकत्रित करता है। इसे खोलने के लिए:

- अपने ब्राउज़र टूलबार में Odoo Toolbox आइकन पर **राइट-क्लिक** करें और **Options** चुनें।
- या [एक्सटेंशन पॉपअप](./odoo/popup) खोलें और नीचे **Options** लिंक पर क्लिक करें।

Odoo Toolbox के ज़्यादातर फीचर्स इस पेज से सक्षम, अक्षम या कॉन्फ़िगर किए जा सकते हैं।

:::tip
इसे एक्सप्लोर करने में संकोच न करें - एक्सटेंशन को अपना बनाने और उसे अपने वर्कफ़्लो के अनुसार ढालने का यह सबसे अच्छा तरीका है।
:::

## कॉन्फ़िगरेशन एक्सपोर्ट / इंपोर्ट {/* #export-import */}

Options पेज आपको अपनी पूरी कॉन्फ़िगरेशन एक्सपोर्ट और इंपोर्ट करने की भी अनुमति देता है। अपनी सेटिंग्स का बैकअप लेने या उन्हें किसी दूसरे ब्राउज़र या मशीन पर ट्रांसफर करने के लिए उपयोगी।
