# Options

تجمع صفحة Options جميع إعدادات إضافة Odoo Toolbox في مكان واحد. لفتحها:

- **انقر بزر الماوس الأيمن** على أيقونة Odoo Toolbox في شريط أدوات متصفحك، ثم اختر **Options**.
- أو افتح [النافذة المنبثقة للإضافة](./odoo/popup) وانقر على رابط **Options** في الأسفل.

يمكن تفعيل أو تعطيل أو تهيئة معظم ميزات Odoo Toolbox من هذه الصفحة.

:::tip
لا تتردد في استكشافها - فهي أفضل طريقة لجعل الإضافة ملكك وتكييفها وفق سير عملك.
:::

![صفحة Options](/img/options/overview.png)

## تصدير / استيراد التهيئة {/* #export-import */}

تتيح صفحة Options أيضًا تصدير واستيراد تكوينك بالكامل. مفيد لنسخ إعداداتك احتياطيًا أو نقلها إلى متصفح أو جهاز آخر.
