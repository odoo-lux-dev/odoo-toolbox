# الشريط الجانبي التقني

:::warning
تدعم هذه الميزة إصدار Odoo 16 والإصدارات الأحدث فقط.
:::

الشريط الجانبي التقني (Technical Sidebar) هو لوحة فحص عائمة تتراكب مع أي صفحة Odoo. تتيح لك فحص الحقول وأنواعها وخصائصها وبياناتها الوصفية في الوقت الفعلي دون مغادرة الصفحة أو فتح DevTools.

## تفعيل الشريط الجانبي {/* #activate-the-sidebar */}

يُفعّل الشريط الجانبي من [النافذة المنبثقة للإضافة](./popup): انقر على أيقونة الإضافة في شريط أدوات متصفحك، ثم فعّل مفتاح **الشريط الجانبي التقني** (Technical Sidebar). يمكن تفعيله أيضًا من [إعدادات الإضافة](../options).

## نظرة عامة {/* #overview */}

يظهر الشريط الجانبي كلوحة مثبّتة على جانب الصفحة. يحتوي على:

- **معلومات قاعدة البيانات**: تعرض معلومات حول قاعدة البيانات الحالية، مثل اسمها وإصدارها وغير ذلك.
- **معلومات السجل**: تعرض معلومات حول سجل العرض الحالي، مثل معرّفه ونموذجه وغير ذلك.
- **قائمة الحقول**: تعرض جميع حقول النموذج الحالي مع بعض المعلومات التقنية.
- **قائمة الإجراءات**: تعرض جميع الإجراءات المتاحة للنموذج الحالي مع بعض المعلومات التقنية.
- **شريط البحث**: يرشّح قائمة الحقول والإجراءات حسب الاسم التقني، أو التسمية المعروضة، أو النوع.

![الشريط الجانبي التقني - الواجهة](/img/technical-sidebar/interface.png)

:::info
لا يحتاج وضع التصحيح (debug mode) إلى تفعيله للوصول إلى المعلومات.
:::

## الميزات {/* #features */}

### معلومات قاعدة البيانات {/* #database-information */}

تُعرض معلومات حول قاعدة البيانات الحالية في أعلى الشريط الجانبي، بما في ذلك:

- إصدار Odoo
- اسم قاعدة البيانات
- اللغة الحالية
- حالة وضع المطوّر

![الشريط الجانبي التقني - معلومات قاعدة البيانات](/img/technical-sidebar/database-information.png)

### معلومات السجل {/* #record-information */}

تُعرض معلومات حول سجل العرض الحالي أسفل معلومات قاعدة البيانات، بما في ذلك:

- اسم النموذج (مثل `res.partner`، `sale.order`)
- معرّف السجل
- نوع العرض (مثل `form`، `list`، `kanban`)
- نوع الإجراء (مثل `ir.actions.act_window`)
- اسم الإجراء (مثل `عرض الشركاء`)
- معرّف الإجراء
- XML ID للإجراء (مثل `base.action_res_partner_form`)
- سياق الإجراء (مثل `{'search_default_group_by_country': 1}`)

![الشريط الجانبي التقني - معلومات السجل](/img/technical-sidebar/record-information.png)

#### أزرار الإجراءات {/* #action-buttons */}

تتوفر أيضًا عدة أزرار إجراءات في هذا القسم لتنفيذ إجراءات مختلفة:

- عرض حقول النموذج
- عرض حقوق الوصول للنموذج
- عرض قواعد السجلات للنموذج (record rules)
- عرض الإجراءات المتاحة للنموذج
- عرض الإجراء المرتبط بالعرض الحالي
- عرض بيانات السجل الحالي بصيغة JSON

![الشريط الجانبي التقني - أزرار الإجراءات](/img/technical-sidebar/record-actions.png)

### قائمة الحقول والإجراءات {/* #fields-and-actions-list */}

تُدرج حقول وإجراءات النموذج الحالي في الشريط الجانبي مع بعض المعلومات التقنية. تتوفر أيضًا مرشّحات وشريط بحث للعثور بسرعة على حقل أو إجراء محدد.

عند تمرير المؤشر فوق أحد عناصر القائمة، يتم إبرازه على الصفحة، مما يتيح لك تحديده بصريًا.

![الشريط الجانبي التقني - التمرير](/img/technical-sidebar/fields-highlight.png)

### تفاصيل حقل أو إجراء {/* #field-or-action-details */}

من الممكن أيضًا تفعيل وضع يتيح لك النقر على حقل أو إجراء لعرض تفاصيله التقنية في الشريط الجانبي. يمنحك هذا معلومات مركّزة حول ذلك الحقل أو الإجراء تحديدًا.

يُفعّل هذا الوضع عبر النقر على زر الفحص في أعلى يمين الشريط الجانبي.

![الشريط الجانبي التقني - وضع الفحص](/img/technical-sidebar/field-selected.png)
