# بدء الاستخدام

يهدف **Odoo Toolbox** إلى تحسين تجربة مستخدمي ومطوّري Odoo و Odoo.SH عبر إضافة مجموعة متنوعة من الأدوات والميزات.

## التثبيت {/* #installation */}

### Chromium {/* #chromium */}

1. انتقل إلى [Chrome Web Store](https://chromewebstore.google.com/detail/odoo-toolbox/jgobnmpfeomiffhbedhfgbhelcnnelkd)
2. انقر على **إضافة إلى Chrome**
3. أكّد عبر النقر على **إضافة الإضافة**

### Firefox {/* #firefox */}

1. انتقل إلى صفحة [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/odoo-toolbox/)
2. انقر على **إضافة إلى Firefox**
3. أكّد عبر النقر على **إضافة**

بمجرد التثبيت، ستظهر أيقونة Odoo Toolbox في شريط أدوات متصفحك.

---

## البداية السريعة {/* #quick-start */}

### 1. الانتقال إلى نسخة Odoo {/* #navigate-to-odoo */}

افتح متصفحك وانتقل إلى أي نسخة Odoo تعمل بـ **الإصدار 14 أو أحدث**.

### 2. فتح النافذة المنبثقة {/* #open-the-popup */}

انقر على أيقونة **Odoo Toolbox** في شريط أدوات متصفحك لفتح النافذة المنبثقة. من هنا يمكنك:

- تشغيل أو إيقاف **وضع التصحيح** (متاح أيضًا عبر اختصار لوحة المفاتيح)
- تبديل **سمة** الإضافة بين الفاتح والداكن
- الوصول إلى **مشاريع Odoo.SH المفضّلة** لديك
- فتح **صفحة Options** للإعدادات المتقدمة

### 3. فحص الحقول باستخدام الشريط الجانبي التقني {/* #inspect-fields */}

في أي عرض Odoo، يظهر **زر عائم** في الزاوية السفلية اليمنى (افتراضيًا) من الصفحة.

1. انقر على الزر لفتح **الشريط الجانبي التقني** (Technical Sidebar)
2. تصفّح المعلومات التقنية حول الصفحة الحالية (النموذج، الحقول، العرض، إلخ)
3. لمزيد من الدقة، فعّل **وضع اختيار العناصر** عبر النقر على أيقونة المؤشر في أعلى اليمين
4. انقر على أي حقل في الصفحة لإظهار تفاصيله التقنية:
    - اسم الحقل (`name`، `partner_id`، ...)
    - نوع الحقل (`Many2one`، `Char`، `Selection`، ...)
    - خصائص وبيانات وصفية إضافية

### 4. استخدام لوحة DevTools {/* #use-devtools-panel */}

تتيح لك لوحة DevTools التفاعل مع طبقة RPC الخاصة بـ Odoo دون مغادرة متصفحك.

1. افتح **DevTools** في متصفحك (`F12` أو `Ctrl+Shift+I` / `Cmd+Option+I` على Mac)
2. انتقل إلى علامة التبويب **Odoo Toolbox**
3. اختر علامة تبويب للعملية:
    - **Search** - الاستعلام عن السجلات مع مرشّحات النطاق واختيار الحقول
    - **Write / Create / Unlink** - تعديل السجلات باستخدام إدخال JSON
    - **Call Method** - تنفيذ أي method على النموذج
