# ميزات إضافية

تغطي هذه الصفحة الأدوات الصغيرة التي يضيفها Odoo Toolbox إلى واجهة Odoo.SH لتسهيل إدارة المشاريع والفروع اليومية. تتوفر هذه الميزات مباشرةً على [Odoo.SH](https://www.odoo.sh)، دون الحاجة لأي تهيئة.

## اختصارات الفروع {/* #branch-shortcuts */}

![اختصارات الفروع](/img/odoosh/additional-features/shortcuts.png)

### نسخ اسم الفرع {/* #branch-name-copy */}

في صفحة مشروع Odoo.SH، يمتلك كل صف فرع زر **نسخ سريع** بجانب اسم الفرع. انقر عليه لنسخ اسم الفرع الدقيق إلى الحافظة فورًا - عملي لأوامر `git checkout`، أو رسائل الـ commit، أو أسماء المهام.

{/* ![نسخ اسم الفرع](/img/odoosh/additional-features/branch-copy.png) */}

### روابط GitHub {/* #github-links */}

يضيف Odoo Toolbox **رابط GitHub** مباشرًا على كل فرع، يشير إلى الفرع المقابل في مستودع GitHub الخاص بك. لا مزيد من الانتقال إلى GitHub بشكل منفصل والبحث عن الفرع الصحيح.

{/* ![روابط GitHub](/img/odoosh/additional-features/github-links.png) */}

### تكامل المهام {/* #task-integration */}

يمكن لـ Odoo Toolbox ربط فرع Odoo.SH بمهمة في مشروع Odoo الخاص بك. عند اكتشاف تطابق في اسم الفرع، يُعرض رابط مباشر للمهمة بجانب الفرع.

#### كيف يعمل

تحلل الإضافة اسم كل فرع باستخدام التعبير النمطي `/-(\d+)-/`. يُحقّن المعرّف الرقمي الملتقط بعد ذلك في رابط قابل للتخصيص عبر العنصر النائب `{{task_id}}`. يمكن تخصيص كل من التعبير النمطي (regex) والرابط من إعدادات الإضافة.

النمط الافتراضي يطابق الصيغة: `VERSION-TASKID-OPTIONAL_DESCRIPTION`

أمثلة على أسماء الفروع المتعرّف عليها: `17.0-12345-my-feature`، `15.0-6789-fixes`

لتهيئة الرابط الهدف، انتقل إلى **إعدادات الإضافة** وأدخل رابطك مع العنصر النائب `{{task_id}}`. مثلًا:

```
https://my-odoo.com/odoo/project/task/{{task_id}}
```

:::tip
يمكنك تعيين رابط مخصص لكل مفضّل من صفحة **SH Favorites** في إعدادات الإضافة.
:::
