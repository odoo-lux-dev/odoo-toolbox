# Odoo.SH

O Odoo Toolbox adiciona um conjunto de funcionalidades diretamente na interface do Odoo.SH para simplificar a gestão de projetos e ramos. Estas funcionalidades apenas estão disponíveis no [Odoo.SH](https://www.odoo.sh).

## O que está incluído {/* #whats-included */}

### [Projetos favoritos](./favorites) {/* #project-favorites */}

A funcionalidade principal do Odoo.SH. Adicione aos favoritos os seus projetos mais utilizados, atribua-lhes nomes de apresentação personalizados e mantenha-os ordenados como preferir - para que encontre sempre o que precisa num relance.

### [Funcionalidades adicionais](./additional-features) {/* #additional-features */}

Utilitários que melhoram o seu fluxo de trabalho diário no Odoo.SH: cópia do nome do ramo, ligações GitHub, integração de tarefas, indicadores de estado de compilação adaptados a daltónicos e muito mais.
