# Projetos favoritos

Os projetos favoritos são a funcionalidade principal da parte Odoo.SH do Odoo Toolbox. Permitem-lhe fixar os seus projetos Odoo.SH mais utilizados, atribuir-lhes nomes personalizados e reordená-los como preferir - para que possa aceder ao que precisa num relance, sem ter de procurar na lista completa de projetos.

Os favoritos estão acessíveis a partir de três locais:

- O **popup da extensão** - a partir de qualquer página, mesmo fora do Odoo.SH.
- A **página inicial do Odoo.SH** - os favoritos são apresentados no topo da lista de projetos.
- A **página de opções da extensão** - uma secção dedicada à gestão dos seus favoritos.

## Adicionar um favorito {/* #adding-a-favorite */}

A partir da lista de projetos no [Odoo.SH](https://www.odoo.sh), o Odoo Toolbox adiciona um ícone ⭐ junto a cada projeto. Clique nele para fixar o projeto nos seus favoritos.

![Projetos favoritos - adicionar um favorito](/img/odoosh/favorites/projects-list.png)

:::tip
Pode adicionar tantos projetos aos favoritos quanto desejar. A ordem em que aparecem é totalmente personalizável.
:::

## Renomear um favorito {/* #renaming-a-favorite */}

Por defeito, um favorito apresenta o nome do projeto tal como aparece no Odoo.SH. Pode atribuir um nome de apresentação personalizado, o que é útil quando os nomes dos projetos são longos, pouco claros ou quando gere vários projetos semelhantes.

Para renomear um favorito, aceda às opções da extensão Odoo Toolbox e, em seguida, à secção "SH Favorites". Clique no botão de edição do favorito que pretende renomear, escreva o novo nome e prima Enter para guardar.

![Projetos favoritos - renomear](/img/odoosh/favorites/rename-favorite.png)

## Reordenar favoritos {/* #reordering-favorites */}

Os favoritos podem ser reordenados através de arrastar e largar a partir das opções da extensão. Utilize a pega de arrastar à esquerda de cada favorito para o mover para cima ou para baixo na lista. A ordem que definir é a que será apresentada na página inicial do Odoo.SH e no popup da extensão.

## Remover um favorito {/* #removing-a-favorite */}

Clique novamente no ícone ⭐ de um projeto fixado para o remover dos seus favoritos. O projeto permanece normalmente acessível na lista completa de projetos do Odoo.SH. Também pode remover um favorito a partir das opções da extensão, clicando no botão de eliminação à direita do favorito que pretende remover.

## Aceder aos favoritos a partir do popup {/* #popup-access */}

O popup da extensão apresenta os seus favoritos em todas as páginas, incluindo fora do Odoo.SH. Clique num favorito no popup para abrir o projeto correspondente no [Odoo.SH](https://www.odoo.sh) diretamente.

![Projetos favoritos - acesso a partir do popup](/img/odoosh/favorites/popup-list.png)

:::info
Para abrir um projeto num novo separador, mantenha premida a tecla <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> no Mac) enquanto clica no favorito no popup. Também pode clicar com o botão do meio para abrir o projeto num novo separador.
:::
