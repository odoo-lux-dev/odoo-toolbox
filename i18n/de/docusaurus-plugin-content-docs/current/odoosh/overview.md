# Odoo.SH

Odoo Toolbox fügt eine Reihe von Funktionen direkt in die Odoo.SH-Oberfläche ein, um die Projekt- und Branch-Verwaltung zu vereinfachen. Diese Funktionen sind nur auf [Odoo.SH](https://www.odoo.sh) verfügbar.

## Was enthalten ist {/* #whats-included */}

### [Projekt-Favoriten](./favorites) {/* #project-favorites */}

Die Hauptfunktion für Odoo.SH. Markieren Sie Ihre am häufigsten verwendeten Projekte mit einem Stern, geben Sie ihnen benutzerdefinierte Anzeigenamen und sortieren Sie sie so, wie Sie es möchten - damit Sie immer auf einen Blick finden, was Sie brauchen.

### [Zusätzliche Funktionen](./additional-features) {/* #additional-features */}

Dienstprogramme, die Ihren täglichen Odoo.SH-Workflow verbessern: Branch-Namen kopieren, GitHub-Links, Task-Integration, farbenblindenfreundliche Build-Statusindikatoren und mehr.
