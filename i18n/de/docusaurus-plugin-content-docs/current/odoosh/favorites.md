# Projekt-Favoriten

Projekt-Favoriten sind die Hauptfunktion des Odoo.SH-Teils von Odoo Toolbox. Sie ermöglichen es Ihnen, Ihre am häufigsten verwendeten Odoo.SH-Projekte anzuheften, ihnen benutzerdefinierte Namen zu geben und sie nach Belieben neu anzuordnen - damit Sie mit einem Blick auf das zugreifen können, was Sie brauchen, ohne die vollständige Projektliste durchsuchen zu müssen.

Favoriten sind von drei Orten aus erreichbar:

- Das **Erweiterungs-Popup** - von jeder Seite, auch außerhalb von Odoo.SH.
- Die **Odoo.SH-Startseite** - Favoriten werden oben in der Projektliste angezeigt.
- Die **Erweiterungsoptionsseite** - ein eigener Abschnitt zur Verwaltung Ihrer Favoriten.

## Einen Favoriten hinzufügen {/* #adding-a-favorite */}

Aus der Projektliste auf [Odoo.SH](https://www.odoo.sh) fügt Odoo Toolbox ein ⭐-Symbol neben jedem Projekt hinzu. Klicken Sie darauf, um das Projekt zu Ihren Favoriten hinzuzufügen.

![Projekt-Favoriten - Favorit hinzufügen](/img/odoosh/favorites/projects-list.png)

:::tip
Sie können so viele Projekte zu Ihren Favoriten hinzufügen, wie Sie möchten. Die Reihenfolge, in der sie erscheinen, ist vollständig anpassbar.
:::

## Einen Favoriten umbenennen {/* #renaming-a-favorite */}

Standardmäßig zeigt ein Favorit den Projektnamen so an, wie er auf Odoo.SH erscheint. Sie können einen benutzerdefinierten Anzeigenamen vergeben, was nützlich ist, wenn Projektnamen lang, unklar sind oder wenn Sie mehrere ähnliche Projekte verwalten.

Um einen Favoriten umzubenennen, gehen Sie zu den Odoo Toolbox-Erweiterungsoptionen und dann zum Abschnitt "SH Favorites". Klicken Sie auf die Bearbeiten-Schaltfläche des Favoriten, den Sie umbenennen möchten, geben Sie den neuen Namen ein und drücken Sie die Eingabetaste, um zu speichern.

![Projekt-Favoriten - Umbenennen](/img/odoosh/favorites/rename-favorite.png)

## Favoriten neu anordnen {/* #reordering-favorites */}

Favoriten können per Drag-and-Drop über die Erweiterungsoptionen neu angeordnet werden. Verwenden Sie den Ziehgriff auf der linken Seite jedes Favoriten, um ihn in der Liste nach oben oder unten zu verschieben. Die von Ihnen festgelegte Reihenfolge ist die, die auf der Odoo.SH-Startseite und im Erweiterungs-Popup angezeigt wird.

## Einen Favoriten entfernen {/* #removing-a-favorite */}

Klicken Sie erneut auf das ⭐-Symbol bei einem angehefteten Projekt, um es aus Ihren Favoriten zu entfernen. Das Projekt bleibt normal in der vollständigen Odoo.SH-Projektliste zugänglich. Sie können einen Favoriten auch über die Erweiterungsoptionen entfernen, indem Sie auf die Löschen-Schaltfläche rechts neben dem Favoriten klicken, den Sie entfernen möchten.

## Zugriff auf Favoriten über das Popup {/* #popup-access */}

Das Erweiterungs-Popup zeigt Ihre Favoriten auf allen Seiten an, einschließlich außerhalb von Odoo.SH. Klicken Sie im Popup auf einen Favoriten, um das entsprechende Projekt direkt auf [Odoo.SH](https://www.odoo.sh) zu öffnen.

![Projekt-Favoriten - Zugriff über das Popup](/img/odoosh/favorites/popup-list.png)

:::info
Um ein Projekt in einem neuen Tab zu öffnen, halten Sie <kbd>Ctrl</kbd> (<kbd>Cmd</kbd> auf Mac) gedrückt, während Sie im Popup auf den Favoriten klicken. Sie können auch mit der mittleren Maustaste klicken, um das Projekt in einem neuen Tab zu öffnen.
:::
