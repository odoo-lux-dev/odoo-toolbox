# Optionen

Die Optionsseite bündelt alle Einstellungen von Odoo Toolbox an einem Ort. Um sie zu öffnen:

- **Klicken Sie mit der rechten Maustaste** auf das Odoo Toolbox-Symbol in der Symbolleiste Ihres Browsers und wählen Sie **Optionen**.
- Oder öffnen Sie das [Erweiterungs-Popup](./odoo/popup) und klicken Sie auf den Link **Optionen** am unteren Rand.

Die meisten Odoo Toolbox-Funktionen können auf dieser Seite aktiviert, deaktiviert oder konfiguriert werden.

:::tip
Zögern Sie nicht, sie zu erkunden - es ist der beste Weg, die Erweiterung zu Ihrem eigenen zu machen und an Ihren Workflow anzupassen.
:::

![Optionsseite](/img/options/overview.png)

## Konfiguration exportieren / importieren {/* #export-import */}

Die Optionsseite ermöglicht Ihnen auch den Export und Import Ihrer gesamten Konfiguration. Nützlich, um Ihre Einstellungen zu sichern oder auf einen anderen Browser oder ein anderes Gerät zu übertragen.
