# Erweiterungs-Popup

Das Erweiterungs-Popup vereint die häufigsten Aktionen in einem einzigen Klick auf das Erweiterungssymbol in der Symbolleiste Ihres Browsers.

## Das Popup öffnen {/* #opening-the-popup */}

Klicken Sie auf das **Odoo Toolbox**-Symbol in der Symbolleiste Ihres Browsers. Das Popup öffnet sich sofort.

:::tip
Wenn das Symbol nicht sichtbar ist, kann es im Erweiterungsmenü Ihres Browsers ausgeblendet sein. Heften Sie es an, um schnellen Zugriff zu haben.
:::

![Odoo Toolbox - Popup](/img/popup/popup.png)

## Debug-Modus {/* #debug-mode */}

Das Popup zeigt den aktuellen Status des Debug-Modus an und ermöglicht Ihnen, ihn einfach umzuschalten. Der Debug-Modus wird auf Odoo-Seiten automatisch aktiviert, wenn er in der Erweiterung aktiviert ist.

- **1 Klick**: schaltet den Debug-Modus ein/aus
- **2 Klicks**: aktiviert den Assets-Debug-Modus (entspricht `?debug=assets`)
- **3 Klicks**: aktiviert den Assets- und Test-Modus (entspricht `?debug=assets,tests`)

## Thema der Erweiterung {/* #extension-theme */}

Wählen Sie das Erscheinungsbild der Odoo Toolbox-Oberfläche (DevTools Panel, Technische Seitenleiste, Popup, Optionen):

- **Light**: helles Thema
- **Dark**: dunkles Thema

## Technische Seitenleiste {/* #technical-sidebar */}

Aktivieren oder deaktivieren Sie die [Technische Seitenleiste](./technical-sidebar) direkt aus dem Popup, ohne die Einstellungen öffnen zu müssen.

## Odoo.SH-Favoriten {/* #odoosh-favorites */}

Das Popup zeigt die Liste Ihrer bevorzugten Odoo.SH-Projekte für den schnellen Zugriff an. Klicken Sie auf einen Favoriten, um das entsprechende Projekt direkt auf [Odoo.SH](https://www.odoo.sh) zu öffnen.

Diese Funktion ist auf allen Seiten verfügbar, auch außerhalb von Odoo.SH.

:::info
Das Hinzufügen und Entfernen von Favoriten erfolgt direkt über die Odoo.SH-Oberfläche. Das Umbenennen und Neuordnen erfolgt über die Erweiterungsoptionen.

Weitere Informationen finden Sie in den Abschnitten [Projekt-Favoriten](../odoosh/favorites) und [Optionen](../options).
:::
