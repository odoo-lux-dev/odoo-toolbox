# Zusätzliche Funktionen

Diese Seite behandelt die leichteren Funktionen von Odoo Toolbox, die Ihre tägliche Erfahrung auf Odoo-Instanzen verbessern, ohne selbst ein vollwertiges Werkzeug zu sein.

## Technischer Modellname {/* #model-name */}

Auf jeder Odoo-Datensatzseite zeigt Odoo Toolbox den technischen Namen des aktuellen Modells direkt in der Oberfläche an. Diese Information war früher in der Seiten-URL vorhanden, ist aber seit Version 17.2 nicht mehr der Fall.

Dieser Modellname wird daher nur auf Odoo-Version 17.2 und höher angezeigt.

![Technischer Modellname](/img/additional-features/technical-name.png)

:::tip
Dies ist besonders nützlich, wenn Sie Python-Code, Zugriffsregeln oder XML-Ansichten schreiben und den genauen Modellnamen benötigen.
:::

## PDF-/HTML-Berichtsvorschau {/* #report-preview */}

Odoo Toolbox fügt einen schnellen Zugriff auf Berichte direkt über die Druckoptionen eines Datensatzes hinzu. Sie können den zugehörigen Bericht im **PDF**- oder **HTML**-Format aufrufen, ohne den Bericht jedes Mal herunterladen zu müssen.

![Berichtsvorschau](/img/additional-features/report-preview.png)

## Schnelle Anmeldebuttons

Odoo Toolbox fügt schnelle Anmeldebuttons auf Odoo-Anmeldeseiten hinzu. Drei Buttons sind verfügbar:

- Admin
- Demo
- Portal

:::tip
Dies ist besonders nützlich auf Entwicklungs- oder Testinstanzen sowie auf Odoo-Runbots.
:::

![Schnelle Anmeldebuttons](/img/additional-features/quick-connect-buttons.png)
