# Odoo.SH

Odoo Toolbox voegt een set functies direct toe aan de Odoo.SH-interface om project- en branchbeheer te vereenvoudigen. Deze functies zijn alleen beschikbaar op [Odoo.SH](https://www.odoo.sh).

## Wat is inbegrepen {/* #whats-included */}

### [Projectfavorieten](./favorites) {/* #project-favorites */}

De paradepaard voor Odoo.SH. Markeer uw meest gebruikte projecten, geef ze aangepaste weergavenamen en houd ze gesorteerd zoals u wilt - zodat u altijd in één oogopslag vindt wat u nodig heeft.

### [Aanvullende functies](./additional-features) {/* #additional-features */}

Hulpprogramma's die uw dagelijkse Odoo.SH-workflow verbeteren: branchnaam kopiëren, GitHub-links, taakintegratie, kleurenblindvriendelijke build-statusindicatoren en meer.
