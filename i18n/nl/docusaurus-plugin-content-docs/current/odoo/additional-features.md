# Aanvullende functies

Deze pagina behandelt de lichtere functies van Odoo Toolbox die uw dagelijkse ervaring op Odoo-instanties verbeteren, zonder op zichzelf een volwaardig hulpmiddel te vormen.

## Technische modelnaam {/* #model-name */}

Op elke Odoo-recordpagina toont Odoo Toolbox de technische naam van het huidige model direct in de interface. Deze informatie was historisch aanwezig in de URL van de pagina, maar dit is niet meer het geval sinds versie 17.2.

Deze modelnaam wordt daarom alleen weergegeven op Odoo-versie 17.2 en later.

![Technische modelnaam](/img/additional-features/technical-name.png)

:::tip
Dit is vooral handig bij het schrijven van Python-code, toegangsregels of XML-weergaven wanneer u de exacte modelnaam nodig heeft.
:::

## PDF / HTML-rapportvoorbeeld {/* #report-preview */}

Odoo Toolbox voegt snelle toegang tot rapporten toe, direct vanuit de afdrukopties van een record. U kunt het bijbehorende rapport in **PDF**- of **HTML**-formaat openen zonder het rapport elke keer te hoeven downloaden.

![Rapportvoorbeeld](/img/additional-features/report-preview.png)

## Snelle inlogknoppen

Odoo Toolbox voegt snelle inlogknoppen toe op Odoo-inlogpagina's. Er zijn drie knoppen beschikbaar:

- Admin
- Demo
- Portal

:::tip
Dit is vooral handig op ontwikkelings- of testinstanties, evenals op Odoo-runbots.
:::

![Snelle inlogknoppen](/img/additional-features/quick-connect-buttons.png)
