# Odoo

Odoo Toolbox verrijkt uw ervaring op elke Odoo-instantie met een set tools ontworpen voor ontwikkelaars en powerusers. Deze functies zijn beschikbaar op alle ondersteunde Odoo-databases (v14+).

## Wat is inbegrepen {/* #whats-included */}

### [Extensie-popup](./popup) {/* #extension-popup */}

Snelle toegang tot de meest voorkomende ontwikkelaarsacties: schakel de debugmodus in/uit, wijzig het extensiethema en navigeer naar uw Odoo.SH-favorieten.

### [Technische zijbalk](./technical-sidebar) {/* #technical-sidebar */}

Een zwevend inspectiepaneel dat over elke Odoo-pagina wordt gelegd. Klik op een veld om de technische naam, het type en de metadata in real-time weer te geven.

### [DevTools-paneel](./devtools-panel) {/* #devtools-panel */}

Een volledige RPC-testinterface ingebed in de DevTools van uw browser. Bevraag modellen, maak of bewerk records en roep aangepaste methoden aan, zonder uw browser te verlaten.

### [Aanvullende functies](./additional-features) {/* #additional-features */}

Kleinere functies die uw Odoo-ervaring verbeteren: weergave van de technische modelnaam op records, PDF/HTML-rapportgeneratie en meer.
