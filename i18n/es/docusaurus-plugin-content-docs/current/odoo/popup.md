# Popup de la extensión

El popup de la extensión reúne las acciones más comunes en un solo clic en el icono de la extensión en la barra de herramientas del navegador.

## Abrir el popup {/* #opening-the-popup */}

Haga clic en el icono **Odoo Toolbox** en la barra de herramientas de su navegador. El popup se abre inmediatamente.

:::tip
Si el icono no es visible, puede que esté oculto en el menú de extensiones de su navegador. Fíjelo para tener un acceso rápido.
:::

![Odoo Toolbox - Popup](/img/popup/popup.png)

## Modo debug {/* #debug-mode */}

El popup muestra el estado actual del modo debug y permite cambiarlo fácilmente. El modo debug se activa automáticamente en las páginas Odoo si está activado en la extensión.

- **1 clic**: activa/desactiva el modo debug
- **2 clics**: activa el modo debug assets (equivalente a `?debug=assets`)
- **3 clics**: activa el modo tests assets (equivalente a `?debug=assets,tests`)

## Tema de la extensión {/* #extension-theme */}

Elija la apariencia de la interfaz de Odoo Toolbox (panel DevTools, barra lateral técnica, popup, opciones):

- **Light**: tema claro
- **Dark**: tema oscuro

## Barra lateral técnica {/* #technical-sidebar */}

Active o desactive la [barra lateral técnica](./technical-sidebar) directamente desde el popup, sin tener que abrir los ajustes.

## Favoritos Odoo.SH {/* #odoosh-favorites */}

El popup muestra la lista de sus proyectos favoritos de Odoo.SH para un acceso rápido. Haga clic en un favorito para abrir directamente el proyecto correspondiente en [Odoo.SH](https://www.odoo.sh).

Esta funcionalidad está disponible en todas las páginas, incluso fuera de Odoo.SH.

:::info
La adición y eliminación de favoritos se realiza directamente desde la interfaz de Odoo.SH. El renombrado y la reorganización se hacen mediante las opciones de la extensión.

Para más información, consulte las secciones [Proyectos favoritos](../odoosh/favorites) y [Options](../options).
:::
