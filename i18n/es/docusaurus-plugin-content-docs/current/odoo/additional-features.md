# Funcionalidades adicionales

Esta página reúne las funcionalidades más ligeras de Odoo Toolbox que mejoran su experiencia diaria en las instancias Odoo, sin constituir una herramienta por sí mismas.

## Nombre técnico del modelo {/* #model-name */}

En cualquier página de registro Odoo, Odoo Toolbox muestra el nombre técnico del modelo actual directamente en la interfaz. Esta información estaba históricamente presente en la URL de la página, pero ya no lo está desde la versión 17.2.

Este modelo se muestra, por tanto, únicamente en las versiones 17.2 y posteriores de Odoo.

![Nombre técnico del modelo](/img/additional-features/technical-name.png)

:::tip
Esta información es particularmente útil cuando escribe código Python, reglas de acceso o vistas XML y necesita el nombre exacto del modelo.
:::

## Vista previa de informes PDF/HTML {/* #report-preview */}

Odoo Toolbox añade un acceso rápido a los informes directamente desde las opciones de impresión de un registro. Puede acceder al informe asociado en formato **PDF** o **HTML** sin tener que descargar el informe cada vez.

![Vista previa de informes](/img/additional-features/report-preview.png)

## Botones de conexión rápida

Odoo Toolbox añade botones de conexión rápida en las páginas de inicio de sesión de Odoo. Hay tres botones disponibles:

- Admin
- Demo
- Portal

:::tip
Esto es particularmente útil en instancias de desarrollo o de prueba, así como en los runbots de Odoo.
:::

![Botones de conexión rápida](/img/additional-features/quick-connect-buttons.png)
