# Odoo.SH

Odoo Toolbox añade un conjunto de funcionalidades directamente en la interfaz de Odoo.SH para simplificar la gestión de proyectos y ramas. Estas funcionalidades solo están disponibles en [Odoo.SH](https://www.odoo.sh).

## Lo que incluye {/* #whats-included */}

### [Proyectos favoritos](./favorites) {/* #project-favorites */}

La funcionalidad estrella para Odoo.SH. Marque como favoritos sus proyectos más utilizados, asígneles nombres de visualización personalizados y manténgalos ordenados como desee. Para encontrar lo que necesita de un vistazo.

### [Funcionalidades adicionales](./additional-features) {/* #additional-features */}

Utilidades que mejoran su flujo de trabajo diario en Odoo.SH: copia del nombre de rama, enlaces GitHub, integración de tareas, indicadores de estado de builds adaptados para daltónicos, y más.
