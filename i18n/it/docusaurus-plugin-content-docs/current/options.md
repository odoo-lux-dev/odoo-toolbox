# Options

La pagina Options centralizza tutte le impostazioni di Odoo Toolbox. Per aprirla:

- Faccia **clic destro** sull'icona di Odoo Toolbox nella barra degli strumenti del Suo browser e selezioni **Options**.
- Oppure apra il [popup dell'estensione](./odoo/popup) e clicchi sul link **Options** in basso.

La maggior parte delle funzionalità di Odoo Toolbox può essere attivata, disattivata o configurata da questa pagina.

:::tip
Non esiti a esplorarla: è il modo migliore per personalizzare l'estensione e adattarla al Suo flusso di lavoro.
:::

![Pagina Options](/img/options/overview.png)

## Esportazione / importazione della configurazione {/* #export-import */}

La pagina Options permette inoltre di esportare e importare l'intera configurazione. Utile per salvare le Sue impostazioni o trasferirle su un altro browser o un'altra macchina.
