# Popup dell'estensione

Il popup dell'estensione riunisce le azioni più comuni in un solo clic sull'icona dell'estensione nella barra degli strumenti del browser.

## Aprire il popup {/* #opening-the-popup */}

Clicchi sull'icona **Odoo Toolbox** nella barra degli strumenti del Suo browser. Il popup si apre immediatamente.

:::tip
Se l'icona non è visibile, potrebbe essere nascosta nel menu delle estensioni del Suo browser. La fissi per un accesso rapido.
:::

![Odoo Toolbox - Popup](/img/popup/popup.png)

## Modalità debug {/* #debug-mode */}

Il popup visualizza lo stato attuale della modalità debug e permette di attivarla/disattivarla facilmente. La modalità debug viene attivata automaticamente sulle pagine Odoo quando è attivata nell'estensione.

- **1 clic**: attiva/disattiva la modalità debug
- **2 clic**: attiva la modalità debug assets (equivalente a `?debug=assets`)
- **3 clic**: attiva la modalità assets e tests (equivalente a `?debug=assets,tests`)

## Tema dell'estensione {/* #extension-theme */}

Scegli l'aspetto dell'interfaccia di Odoo Toolbox (pannello DevTools, Technical Sidebar, popup, options):

- **Light**: tema chiaro
- **Dark**: tema scuro

## Technical Sidebar {/* #technical-sidebar */}

Attivi o disattivi il [Technical Sidebar](./technical-sidebar) direttamente dal popup, senza dover aprire le impostazioni.

## Preferiti Odoo.SH {/* #odoosh-favorites */}

Il popup visualizza l'elenco dei Suoi progetti Odoo.SH preferiti per un accesso rapido. Clicchi su un preferito per aprire direttamente il progetto corrispondente su [Odoo.SH](https://www.odoo.sh).

Questa funzionalità è disponibile su tutte le pagine, anche al di fuori di Odoo.SH.

:::info
L'aggiunta e la rimozione dei preferiti avvengono direttamente dall'interfaccia Odoo.SH. La rinomina e il riordino vengono effettuati tramite le opzioni dell'estensione.

Per maggiori informazioni, consulti le sezioni [Progetti preferiti](../odoosh/favorites) e [Options](../options).
:::
